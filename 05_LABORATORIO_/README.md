# Laboratorio

Esta carpeta es un espacio de prueba libre dentro del libro. Su objetivo no es introducir contenido nuevo del temario, sino ofrecer un lugar para experimentar, combinar ideas vistas en distintas fases y preparar variantes propias sin alterar los notebooks principales.

## Estado actual

- [01_Sala_a.ipynb](01_Sala_a.ipynb) es el cuaderno base del laboratorio; actualmente contiene una celda Markdown y no incluye código.
- El laboratorio puede crecer de forma incremental cuando haga falta una práctica transversal o una prueba aislada.
- A diferencia de las fases temáticas, aquí no se exige una secuencia lineal de aprendizaje.

## Criterio de uso

- Usa esta carpeta para pruebas manuales, mini experimentos o integraciones entre fases.
- Evita mover aquí contenido que pertenezca de forma natural a una fase o a un proyecto final.
- Si en el futuro se añaden más salas, conviene mantener este README actualizado con su propósito.

Para preparar el entorno y conocer las limitaciones de los ejemplos, consulta el [README principal](../README.md).
