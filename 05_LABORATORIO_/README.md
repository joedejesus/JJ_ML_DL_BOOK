# Laboratorio

Esta carpeta es un espacio complementario del libro para experimentar, combinar ideas de distintas fases y preparar variantes propias sin alterar los notebooks principales. No requiere seguir una secuencia concreta ni completar antes todas las fases.

## Estado actual

- [01_Sala_a.ipynb](01_Sala_a.ipynb) es el cuaderno base del laboratorio; actualmente contiene una celda Markdown y no incluye código.
- Puedes añadir tus propios apuntes y pruebas a una copia local del cuaderno.

## Criterio de uso

- Usa esta carpeta para pruebas manuales, mini experimentos o integraciones entre fases.
- Evita mover aquí contenido que pertenezca de forma natural a una fase o a un proyecto final.

Para preparar el entorno y conocer las limitaciones de los ejemplos, consulta el [README principal](../README.md). Las condiciones para modificar y compartir el contenido se describen en la [licencia](../LICENSE).
