# Código de conducta

JJ ML DL BOOK busca ofrecer un entorno respetuoso y útil para aprender, plantear dudas y revisar cuestiones técnicas. Estas pautas se aplican a las interacciones en el repositorio, incluidos issues, Discussions y otros espacios públicos del proyecto.

## Conducta esperada

Al participar:

- trata a las demás personas con respeto y buena fe;
- centra las críticas en las ideas o implementaciones, no en las personas;
- aporta contexto claro cuando informes de un problema o plantees una propuesta;
- respeta el enfoque educativo del proyecto y las condiciones de [LICENSE](LICENSE);
- actúa con prudencia al tratar datos, seguridad, automatización y posibles impactos sobre terceros.

## Conductas no aceptables

No se admiten el acoso, las amenazas, los ataques personales ni el lenguaje discriminatorio o degradante. Tampoco se admite publicar datos personales ajenos sin autorización, enviar spam, promover usos dañinos o presionar para obtener soporte o permisos que el proyecto no ofrece.

## Moderación

El titular podrá editar, ocultar, cerrar o rechazar interacciones y propuestas que incumplan estas pautas o no encajen con el alcance del proyecto.

Para comunicar problemas de seguridad, consulta [SECURITY.md](SECURITY.md). Las formas de participación se describen en [CONTRIBUTING.md](CONTRIBUTING.md). Este código no sustituye las condiciones de la [licencia](LICENSE).
